# Documentation Index

This directory contains all project documentation organized by purpose.

## Directory Structure

### Working Documents (`working/`)

Active, living documents updated as work progresses:

- **`working/plans/`** - Development plans with task tracking
- **`working/research/`** - Research findings and decision documentation
- **`working/error-logs.md`** - Error tracking and solutions

### Contracts (`contracts/`)

Formal contracts defining interfaces:

- **`contracts/api/`** - API endpoint contracts
- **`contracts/agents/`** - Inter-agent communication contracts

### Architecture (`architecture/`)

Architecture decisions and system design:

- **`architecture/decisions/`** - Architecture Decision Records (ADRs)

### Reference (`reference/`)

Reference documentation and guides:

- **`reference/`** - General reference materials

## Usage Guidelines

### Before Starting Work

1. Check `working/plans/` for existing plans
2. Check `contracts/` for relevant contracts
3. Check `working/research/` for related research
4. Use semantic search to discover relevant docs

### Creating New Documents

- Use templates from each directory
- Follow naming conventions
- Update relevant README indexes
- Link related documents

### Updating Documents

- Keep documents current as work progresses
- Update todos in plans
- Version contracts when they change
- Document decisions in ADRs

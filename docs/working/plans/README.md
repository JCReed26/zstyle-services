# Plans Index

Active development plans tracked in markdown files.

## Purpose

Plans document the approach, tasks, and progress for features and improvements. They serve as:
- Task breakdowns with clear ownership
- Progress tracking via todos
- Coordination between sub-agents
- Historical record of how work was done

## Plan Status

Plans use status indicators:
- ⏳ **Pending** - Not yet started
- 🔄 **In Progress** - Currently being worked on
- ✅ **Completed** - Finished
- 🚫 **Blocked** - Blocked by dependencies or issues
- ❌ **Cancelled** - No longer needed

## Creating a Plan

1. Use the template: `TEMPLATE.md`
2. Name file: `[feature-name].md`
3. Fill in objective, context, tasks
4. Assign sub-agents to tasks
5. Update this README with plan link

## Best Practices

- **Check existing plans** before creating new ones
- **Update progress** as work happens
- **Link related plans** when dependencies exist
- **Close plans** when complete (move to archive if needed)
- **Reference contracts** when APIs are involved

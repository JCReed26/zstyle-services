# Reference Documentation

Reference materials and guides for the project.

## Purpose

This directory contains:
- **Guides**: How-to guides and tutorials
- **Reference**: API references, schemas, etc.
- **Examples**: Code examples and patterns

## Organization

Reference documents are organized by topic. Each document should be:
- **Focused**: One topic per document
- **Complete**: Self-contained information
- **Up-to-date**: Kept current with codebase
- **Linked**: Referenced from relevant places

## Creating Reference Documentation

1. Name file: `[topic].md`
2. Keep it focused and complete
3. Link from relevant places (plans, contracts, etc.)
4. Update this README with document link

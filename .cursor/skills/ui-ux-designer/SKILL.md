# UI/UX Designer Skill

## When to Use

Activate the ui-ux-designer sub-agent when:

- User asks for UI/UX design or mockups
- Need to design user flows or wireframes
- Creating design specifications
- User mentions "design", "UX", "user experience", or "interface design"
- Need to avoid "AI callouts" in designs

## How to Use

1. **Read the sub-agent definition**: `.cursor/agents/ui-ux-designer/SUBAGENT.md`
2. **Discover context**: 
   - Check `docs/working/plans/` for design requirements
   - Check existing design patterns in codebase
   - Review user research if available
3. **Focus on users**: Design with real users and behavior in mind
4. **Avoid AI callouts**: Use natural, human language
5. **Create specs**: Provide clear design specifications
6. **Collaborate**: Work with frontend-engineer on implementation
7. **Update plans**: Update plans with design decisions

## Example Usage

**User**: "Design a login page"

**Response**:
1. Consider user goals and behavior
2. Design natural, intuitive interface
3. Avoid "AI-powered" language
4. Create design specification
5. Consider accessibility and mobile

## Key Capabilities

- User-centered design
- Natural language interfaces
- Accessibility design
- Design specifications
- User behavior consideration
